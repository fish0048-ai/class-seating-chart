# 班級座位表

打開網頁就能用。名單、座位、加扣分與成績存在 **Google 試算表**（雲端資料庫），平板和筆電會看到同一份資料。

- 上傳班級、座號、姓名（CSV 或 Excel）
- 拖放調座位
- 抽籤
- 分組（手動／隨機，可設每組人數；小組分會加進個人平時成績）
- 實驗室模式（固定 6 組，座位分成六個區塊）
- 加分／扣分（可復原）
- 成績簿、學期統計、Excel 匯入匯出
- 統計圖表：班級分析、全校比較（801～804）、個人分析
- 模擬考能力等級標註（匯入學力診斷統計表）
- 教師課表（對照現在第幾節，點班級可直接去上課）
- 紙本作業檢核（教師建作業、複製連結貼到 Classroom；學生用 Apps Script 連結回報錯題與抽查題號）

線上網址：<https://fish0048-ai.github.io/class-seating-chart/>

已完成功能、資料怎麼存、登入權限、以及**改程式時不能碰壞的地方**，寫在 [docs/專案現況.md](docs/專案現況.md)。之後若要改功能，請先看那一份，避免整站卡住或分組被存檔清掉。

## Google 帳號登入

打開網頁後請用 Google 登入。

- **教師**（目前只有 `chunhsinkuo@kcis.hc.edu.tw`）可加扣分、調座位、抽籤、分組，並進入教師模式
- **其他 Google 帳號**只能看座位表，看不到教師模式，也不能改資料

第一次請先建立 Google 登入（只要做一次）：

1. 打開 [Google Cloud 憑證](https://console.cloud.google.com/apis/credentials)
2. 建立「OAuth 用戶端 ID」，類型選「網頁應用程式」
3. 授權的 JavaScript 來源加上 `https://fish0048-ai.github.io`
4. 把用戶端 ID 貼進登入畫面（或 `docs/config.js` 的 `googleClientId`）
5. 把最新的 `Code.gs` 貼進 Apps Script，並把 `HwStudent.html` 一併新增／更新後再**新增部署**（後端會檢查登入，只有教師能寫入）

## 第一次連上雲端（兩台裝置共用）

請先做一次，之後平板、筆電都讀同一份試算表。

1. 打開 [這份 Google 試算表](https://docs.google.com/spreadsheets/d/1AES93Jv8l65YI2LQ-scVRPqYSLFxtVOD-UqIU99gQSA/edit)
2. 「擴充功能」→「Apps Script」
3. 把本專案根目錄的 `Code.gs` **全部貼上取代舊程式**，按儲存
4. 編輯器上方選函式 `authorizeScript`，按「執行」，允許「連線至外部服務」
5. 同一個 Apps Script 專案新增檔案 `HwStudent`（類型 HTML），把根目錄 `HwStudent.html` 全部貼上
6. 「部署」→「新增部署作業」→類型選「網頁應用程式」
7. 執行身分選「我」，對象選「任何人」，再部署
8. 複製結尾是 `/exec` 的網址（不要用 `/dev` 測試網址）
9. 用教師 Google 帳號登入後，到教師模式 → 設定 → 貼上網址 →「連上雲端」

建議再把同一個網址貼進 `docs/config.js` 的 `apiUrl`，這樣兩台都不必各貼一次。

連上之後，這台瀏覽器裡的舊資料會在雲端是空的時候自動上傳一次，之後就以試算表為準。

## 新增班級與學生（Excel）

1. 教師模式 → **設定與上傳**
2. 按 **下載 Excel 範本**，用 Excel 打開
3. 填 `班級、座號、姓名`（一個檔可以有很多班）
4. 按 **選擇 Excel 檔** 或把檔案拖進去
5. 按 **匯入名單**（成功後會寫進資料庫的「學生」與「班級設定」工作表）

若只要把舊名單整個換掉，先勾「覆蓋這些班級的舊名單」。

如果試算表的「學生」工作表沒出現新班級，請把最新的 `Code.gs` 全部貼進 Apps Script 並**新增部署**，再匯入一次。

## 資料怎麼改

| 想做的事 | 怎麼做 |
| --- | --- |
| 讓平板與筆電共用 | 依上方步驟連上雲端 |
| 新增班級／學生 | 設定與上傳 → 下載 Excel 範本 → 上傳 → 匯入名單 |
| 改座位 | 按住學生卡片拖放 |
| 改分數 | 加分／扣分後點學生。加扣先留在這台，換機前請按「立即同步」。上課排行只顯示加分 |
| 分組上課 | 上課模式按「分組」：設每組人數，可隨機或手動。勾「套用整組」或點側欄小組，加扣會進每位組員的平時成績。小組因誰被扣分，在教師模式 → 成績統計表可看 |
| 實驗室上課 | 切到「實驗室模式」：固定 6 組、座位六個區塊。可依座號或隨機分組，把學生拖到別區即可換組 |
| 用 Excel 改本班名單 | 設定 → 下載本班 Excel → 改完再上傳 |
| 保險備份 | 教師模式可下載 JSON 備份 |
| 模擬考標在座位卡 | 設定與上傳 → 選擇學力診斷「學校能力等級成績統計表」→ 上課模式可開關「模擬考標註」 |

兩台上課請以一台加扣為主。加扣不會一改就上傳；換機前在這台按「立即同步」。舊分頁切到背景時不會把較舊的紀錄蓋掉雲端。

## 紙本作業檢核

教師模式 → **作業檢核**（只有教師帳號看得到）：

1. 先選班級，按「從座位表匯入本班名單」（Email 請之後在試算表 `HW_Students` 補）
2. 填名稱、題數、截止時間後按「建立作業」
3. 按「複製學生作業連結」，貼到 Google Classroom
4. 學生打開連結，用班級＋座號＋姓名進入（三欄要和名單一樣）
5. 勾錯題、選原因、確認紅筆訂正、看抽查題號（對照紙本）、提交
6. 教師可看全班表、複製成績、匯出 CSV、調分、個別延長、未交給 0 或允許補交

這一版**不連 Classroom API**，不會自動建立 Classroom 作業，也不會自動回寫成績。座位表功能不變。

改過程式後，請把 `Code.gs` 與 `HwStudent.html` 貼進 Apps Script 並**新增部署**，GitHub Pages 只更新教師畫面。
