    尚未連線

    1. 打開 Google 試算表（上方會顯示連結）。
    2. 「擴充功能」→「Apps Script」，把最新的 Code.gs 全部貼上並儲存。
    3. 「部署」→「新增部署作業」，類型選「網頁應用程式」。
    4. 執行身分「我」，對象「任何人」，把結尾是 /exec 的網址貼上來，按「連上雲端」。
