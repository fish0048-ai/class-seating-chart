# AI 檢查與 Classroom 更新：職責拆乾淨

日期：2026-11-20  
狀態：已實作  
相關：`2026-10-29-classroom-handouts-design.md`、PR #71（共用寫入路徑；本設計改為 AI 不再寫網站）

## 目標

把兩項功能拆成單一職責，避免「AI 寫網站」與「Classroom 更新網站」兩套規則互蓋，尤其是空白退回後標缺交時網站仍留舊分。

## 決策

| 項目 | 決定 |
| --- | --- |
| Classroom 更新 | **唯一**把繳交狀態／分數寫進網站的路；主目的是讓缺交正確顯示 |
| AI 檢查 | 只檢查「有繳交、還沒分數」；分數寫進 **Classroom 草稿**，不寫網站 |
| 網站分數來源 | AI 寫進 Classroom 後，靠「更新學習講義」（手動或早上自動）同步進網站 |
| 網站建的作業 | AI 可一鍵寫 Classroom 草稿分數 |
| 舊作業（非網站建） | 只顯示輸入清單，老師手動在 Classroom 輸入 |
| UI 入口 | 仍保留兩個選單項，不合併成單一視窗（之後可另開方案 2） |
| 「把分數寫進網站」 | **移除**按鈕與寫入路徑 |

## 職責

### 從 Classroom 更新學習講義

- 以 Classroom 為準同步作業欄：已評分／已繳未評／未繳（含缺交）
- 座位卡、缺交提醒、學期成績的缺交顯示都信這條路（含每天 7 點自動）
- 紙本繳交（`paper`）保留既有保護：Classroom 空白不把紙本改回未繳

### AI 檢查作業

- 讀 Classroom 同名作業；省 token：只有「目前有繳交＋還沒有分數＋有檔可查」才送 Gemini
- 空白退回並標**缺交**（常帶 0 分）：**不算**已有分數、不送 AI
- 檢查結果：網站建立的作業 → 寫 Classroom `draftGrade`；舊作業 → 輸入清單
- 不再呼叫 `importClassroomHandouts`／`applyHandoutColumns_` 寫網站

## 送 AI／缺交對照

| Classroom 現況 | 送 AI | 網站（經更新學習講義） |
| --- | --- | --- |
| 已繳、無分數、有檔 | 要 | 已繳（未評或之後同步分數） |
| 已有分數（發還／草稿 >0；已繳且已發還含 0） | 不要 | 已繳＋分數 |
| 標缺交（含空白退回；常帶 0 分） | 不要 | 未繳／缺交 |
| 未繳／沒按繳交 | 不要 | 未繳 |
| 有按繳交、沒檔案 | 不送 AI；紙本或現況規則 | 依更新結果 |

缺交的 0 分 ≠ 已批改的 0 分。

## 按鈕與流程

1. 選單小字：「更新」＝同步繳交／缺交到網站；「AI 檢查」＝檢查未評分繳交，分數寫進 Classroom  
2. AI 視窗主按鈕＝寫成 Classroom 草稿；拿掉「把分數寫進網站」  
3. 寫入 Classroom 成功後提示：網站要看到分數／缺交請再按「更新學習講義」（或等早上自動）  
4. 日常順序：AI 檢查 → 寫 Classroom → 更新學習講義

## 實作範圍

### 要改

- `docs/app.js`：移除 `applyAiCheckScores` 寫網站路徑（含 `aiCheckScoresForWebsite_`、`syncAiMissingAfterCheck_` 若只服務寫網站）；主按鈕改 Classroom；提示文案  
- `docs/index.html`：拿掉 `btnAiCheckApply`；選單小字  
- `docs/api.js`：移除或縮減僅服務 AI 寫網站的 `fromAiCheck` 特例（若無其他呼叫端）  
- `docs/專案現況.md`：改職責說明；成對規則表「學習講義寫進作業欄」改回只描述 Classroom 更新／自動更新，不再寫 AI 共用寫入  
- e2e／提示若提到「寫進網站」一併改

### 不改

- 不合併單一視窗  
- 不改 7 點自動更新／自動 AI 排程  
- 不改紙本繳交日、複製留言、新增 Classroom 作業  
- `classroomActiveTurnIn_`／`classroomAiAlreadyGraded_`／`classroomScore_` 若已符合上表則沿用，只對齊文件與 UI

## 驗證

- 空白退回標缺交：不送 AI；更新後網站顯示缺交  
- 有繳交無分數：會檢查；網站建的作業可寫 Classroom 草稿  
- 已有分數：不重送  
- 舊作業：無法寫入時只顯示清單，不寫網站  
- 雲端測試（Playwright）通過

## 部署

改到 `Code.gs` 時仍需貼上 Apps Script 並「管理部署 → 編輯現有 → 新版本」。若本實作只動前端，合併 PR 後 Vercel 即可，不必重部後端。

## 不做

- AI 寫分數進網站作業欄  
- 把兩個功能合成一個視窗（另案）  
- 自動把 AI 分數發還給學生（仍只寫草稿，老師在 Classroom 發還）
