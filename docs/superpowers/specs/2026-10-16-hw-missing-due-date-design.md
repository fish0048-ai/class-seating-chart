# 缺交作業：繳交期限與工作天顯示

日期：2026-10-16  
狀態：設計已確認，待實作

## 目標

教師模式「缺交作業」增加**繳交期限**；上課模式座位表與缺交條顯示每位學生各份缺交已過幾個**工作天**（週末與假日不算），方便課堂上直接催繳。

## 決策摘要

| 項目 | 決定 |
| --- | --- |
| 作法 | 擴充現有 `store.hwMissing`，不綁學期成績作業欄 |
| 起算 | 期限當天＝0；隔天起累計工作天（與學期成績 `workDaysLate` 相同） |
| 多份缺交 | 座位卡逐項列出每一份名稱與天數 |
| 舊資料 | 無期限者必須補填；補齊前不上座位表／缺交條 |
| 後端 | 只改前端 `docs/`；不必改 `Code.gs` 或重新部署 |

## 資料

每筆 `store.hwMissing[班名][]` 新增：

- `dueDate`：`YYYY-MM-DD`，完整項目必填

其餘欄位不變：`id`、`title`、`seats`、`note`、`deleted`、`createdAt`、`updatedAt`。

**完整項目**（才會出現在上課座位表／缺交條）：

1. 未刪除（`!deleted`）
2. 至少一位缺交座號
3. 有合法 `dueDate`

`normalizeHwMissingItem_` 必須保留 `dueDate`（空字串可暫時保留給舊資料，但 `saveHwMissing` 新建／更新時拒絕空期限）。

## 計算

沿用 `app.js` 既有：

- `isNonWorkday(dateKey)`：週六日、`TW_HOLIDAYS`、成績規則 `holidays`（額外假日）
- `workDaysLate(dueKey, todayKey)`：從期限隔天起算到今天（含）的工作天數；`today ≤ due` 時為 0

顯示用「今天」的日期鍵（與本地 `scoreDate`／日曆日一致即可，不需存天數進雲端）。

假日規則不另做一份；與學期成績遲交共用。

## 畫面

### 教師模式「缺交作業」

- 新建表單加「繳交期限」日期欄（必填）
- 本班名單每筆顯示期限；無期限標「請補期限」，可在該筆補日期後儲存
- 進入分頁時若本班有缺期限項目，上方提示：「有 N 筆缺交還沒填繳交期限，補齊前不會出現在座位表」
- 點座號增減：立刻存，沿用該筆既有 `dueDate`（無期限時仍可在教師分頁改座號，但催促補期限）
- 無期限時禁止「新建儲存」；補期限儲存時寫入 `dueDate`

### 上課模式

- 缺交條：每份一行，例如 `講義第3回（缺 3 天）：01、05、12`
- 座位卡：該生所有完整缺交逐項列出，例如  
  `缺交 講義第3回 3天`  
  `缺交 習題 1天`  
  （字級較小；多份多行）
- 期限未到或當天：仍顯示缺交，天數為 `0天`

### 不變

刪除整筆、雲端同步、`normalize` 保留 groups／lab、非教師無權限。

### 不做

- 不改成績簿作業欄、不恢復作業檢核
- 不把「已缺交天數」寫進雲端 JSON
- 不改 `Code.gs`／不重新部署 Apps Script

## 驗證

1. 新建：沒填期限無法存；有期限後座位卡出現「名稱 N天」
2. 同一人兩份完整缺交：兩行都顯示
3. 期限＝今天 → `0天`；隔一個工作天 → `1天`；跨週末只算工作天
4. 舊資料無期限：教師分頁可補；補前座位表與缺交條不出現該筆
5. 點座號增減後期限與天數仍正確；畫面仍有座位卡（改 `app.js` 後必查）

## 風險

- 既有雲端缺交名單補期限前，上課模式會暫時看不到那些缺交 → 符合「全部一定要有期限」的決定；教師分頁會明確提示
- 座位卡多份缺交可能較擠 → 用較小字級多行；不改成只顯示最久一份
