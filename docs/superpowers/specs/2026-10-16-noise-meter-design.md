# 課堂測分貝（安靜監測）

日期：2026-10-16  
狀態：設計已確認，待實作

## 目標

在座位表上課畫面加「測分貝」，用本機麥克風做**相對音量**的安靜監測（綠／黃／紅），方便老師提醒班級別太吵。不追求校正過的專業分貝計。

## 決策摘要

| 項目 | 決定 |
| --- | --- |
| 用途 | 課堂安靜監測（紅綠燈），不是精確 dB 報告 |
| 入口 | 工具列按鈕，展開面板（比照「定時」） |
| 門檻 | 預設＋滑桿微調，存這台 `localStorage` |
| 資料 | 不錄音、不上傳、不寫雲端 store |
| 後端 | 不必改 `Code.gs` |

## 行為

### 入口與面板

- 上課工具列、定時旁加「測分貝」（`aria-pressed` 展開／收合）
- 教師模式也可開；不依角色限制（本機麥克風）
- 面板內容：
  - 大色塊＋狀態文字：綠「安靜」／黃「有點吵」／紅「太吵了」
  - 「開始」「停止」
  - 門檻滑桿（調「多吵才變紅」）
  - 小字：「相對參考，非專業分貝計；不會錄音或上傳」

### 顏色規則

- 內部把麥克風 RMS 映射成相對音量 **0～100**
- **紅線**＝老師設定的門檻（預設約 60，可調範圍例如 30～90）
- **黃線**＝紅線 × 0.7（固定比例，不另設第二條滑桿）
- 綠：&lt; 黃線；黃：黃線～紅線；紅：≥ 紅線
- 讀數短時間平滑，減少閃爍

### 麥克風生命週期

- 只有按「開始」才呼叫 `getUserMedia`
- 約束建議關閉：`echoCancellation`、`noiseSuppression`、`autoGainControl`（較適合量相對大小）
- 「停止」、`pagehide`／離開頁面：關閉 MediaStream tracks 與 AudioContext
- **收合面板不自動停止**（避免誤關）；須明確停止或離頁

### 權限與環境

- 需 HTTPS（GitHub Pages／Vercel 可）；`file://` 可能無法用麥克風
- 拒絕權限：面板提示「請允許麥克風後再按開始」，不讓整站空白

### 本機記憶

- `localStorage` 鍵（建議）：門檻數值；可選記住面板展開狀態
- 不寫入 `store`、不呼叫 Apps Script

## 技術落點

| 檔案 | 變更 |
| --- | --- |
| `docs/index.html` | 工具列按鈕＋測分貝面板（可仿 `#timerPanel` 結構） |
| `docs/app.js` | 開／關麥克風、RMS→相對值、顏色、localStorage、離頁清理 |

| `docs/專案現況.md` | 補上課功能說明 |

腳本順序不變。改 `app.js` 後必須確認座位卡仍顯示。

## 不做

- 校正為真實 dB SPL
- 錄音、上傳、雲端歷史
- 全螢幕投影專用模式
- 太吵自動音效或寄信

## 驗證

1. HTTPS 頁按開始 → 權限允許後色塊隨聲音變化  
2. 調高門檻較不易紅、調低較易紅；重新整理後門檻仍在  
3. 停止後麥克風指示應熄滅  
4. 拒絕權限有提示、頁面不空白  
5. 座位卡仍正常  

## 風險

- 不同裝置麥克風靈敏度差大 → 靠滑桿調整，並在 UI 註明「相對參考」
- 部分瀏覽器仍可能套用系統 AGC → 色階可能被壓平；無法完全消除，屬已知限制
