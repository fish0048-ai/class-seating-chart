# 圖表分析重新設計（依「要做的事」分頁）

日期：2026-10-14　狀態：老師已同意方向

## 目標

統計頁從「依成績類型分」改成「依老師要做的事分」。老師主要用途（依重要度）：學期成績核對、考後檢討、找出需要關心的學生、各班比較、上課表現。

## 分頁

取代原本兩排切換（班級／全校／個人 ＋ 總覽／加扣／平時考試／段考／實作／單張考卷），改為一排：

| 分頁 | 範圍 | 內容 |
|---|---|---|
| 成績檢核 | 本班 | 各欄完整度（有分／請假／空白、可疑值）、學生總分組成與缺項、成績色塊總表（空白標記）、及格邊緣 55–60 |
| 考後檢討 | 選一張考卷 | 本班：平均／中位數／及格率／分布／未滿 60／空白／與同類型上一次比較。全校：各班平均與及格率、全校排名（含班排） |
| 需要關心 | 本班／全校 | 一張表，每人列出符合原因，原因多的排前面 |
| 各班比較 | 全校 | 各班學期／平時考試／段考平均與及格率、各班需關心人數、各班表格 |
| 上課表現 | 本班 | 加扣走勢與排行、小組扣分因誰、沒紀錄的人、加分次數 |
| 個人 | 一位學生 | 沿用現有，加「總分組成與缺項」 |

## 規則

- 計分方式不變（空白不算、缺整項時比重重算），只負責顯示與提醒。
- 可疑值：分數 > 滿分、負數、滿分 ≠ 100 但多數分數 > 滿分（疑似填成百分制）。
- 需要關心原因：學期未滿 60、未繳作業、缺交登錄、段考失常、連續退步、成績不穩、上課扣分合計 ≤ −5。
- 同分並列、依日期排序、`01` 與 `1` 視為同座號，沿用既有函式（`rankAmong`、`byColDate`、`readSeatScore`）。

## 移除

散布圖、四分位圖、各類型平均、盒鬚圖、資料盤點小卡（併入成績檢核）、舊的提醒卡牆。

## 實作

在 `docs/app.js` 內重寫統計畫面並刪除不再使用的舊畫面程式；不新增 JS 檔（腳本順序不變）。`Code.gs` 不需改。

## 驗證

以合成資料（含空白、請假、超過滿分、缺段考、同分、跨班共用考卷）用無頭 Chrome 跑每個分頁；確認座位卡存在、沒有 JS 錯誤。
