# 代課與調課優化

日期：2026-10-22  
狀態：設計已確認，待實作

## 目標

1. 課表新增**代課**：「我代別人」與「別人代我」兩種
2. 現有**調課**一起優化（表單簡化、衝突提醒、顯示方向、可編輯）
3. **現有調課資料完整保留**，升級後顯示不變

## 決策摘要

| 項目 | 決定 |
| --- | --- |
| 代課種類 | 兩種都要：`in` 我代別人、`out` 別人代我 |
| 記錄內容 | 日期、節次、班級、對方老師名字、備註 |
| 輸入方式 | 選日期＋節次（系統換算週次與星期） |
| 資料結構 | 代課獨立成 `store.substitutes`；調課沿用 `store.scheduleChanges` 原格式 |
| 課表試算表 | 仍只讀，不寫入 |
| 後端 | `Code.gs` 加代課合併保護，需重新貼上與部署 |

## 資料

### 調課 `store.scheduleChanges[]`（格式不變）

欄位維持：`id`、`weekStart`、`toWeekStart`、`className`、`fromDay`、`fromPeriod`、`toDay`、`toPeriod`、`note`、`deleted`、`createdAt`、`updatedAt`。

新表單選的是日期；儲存時換算：

- `weekStart` = 原日期所在週的週一
- `fromDay` = 原日期星期（週一＝0 … 週五＝4）
- `toWeekStart`、`toDay` 同理

因此**舊資料不需轉換**，新舊資料共用同一套顯示邏輯。編輯舊資料時，由 `weekStart＋fromDay` 反推日期填回表單。

### 代課 `store.substitutes[]`（新增）

| 欄位 | 規則 |
| --- | --- |
| `id` | `SB` 開頭，自動產生 |
| `kind` | `in` 或 `out`，其他值視為無效 |
| `date` | `YYYY-MM-DD`，須為合法日期（回推比對） |
| `period` | 節次字串，必填 |
| `className` | 必填，最多 20 字 |
| `teacher` | 對方老師名字，選填，最多 20 字 |
| `note` | 選填，最多 120 字 |
| `deleted`、`createdAt`、`updatedAt` | 同調課 |

正規化後依 `date` 由新到舊排序，最多保留 200 筆。

### 合併保護

- 前端 `api.js`：`normalizeSubstitutes_`、`mergeSubstitutesProtect_`；`mergeProtectStore` 時用 id＋`updatedAt` 合併，不因一邊沒有資料就清空
- 後端 `Code.gs`：`mergeCloudSubstitutes_`，**所有欄位都要保留**（避免重演缺交 `dueDate` 被清掉）
- 刪除用 `deleted: true` 墓碑，同步後其他裝置也會刪除

## 表單

課表分頁「調課提醒」區改名為**調課與代課**，上方三個模式按鈕：**調課**｜**我代別人**｜**別人代我**。

| 模式 | 欄位 |
| --- | --- |
| 調課 | 原日期、原節次 → 新日期、新節次、班級（自動帶入）、備註 |
| 我代別人 | 日期、節次、班級（文字輸入，可不在名單）、原任課老師、備註 |
| 別人代我 | 日期、節次、班級（自動帶入）、代課老師、備註 |

**自動帶入班級**：依日期找出該週課表（已套用調課），讀該節格子的班級；找不到就讓老師自己填。

**檢查**

| 情況 | 處理 |
| --- | --- |
| 日期是週末或國定假日 | 擋下，提示 |
| 調課原節與新節相同 | 擋下 |
| 調課新節次原本有別班（跨週時會被蓋掉） | 跳確認「那節原本是 XXX，確定要調過去？」 |
| 別人代我：該節是空堂 | 跳確認「那節沒有課，確定？」 |
| 我代別人：該節我原本有課 | 跳確認「那節你有 XXX，會衝堂，確定？」 |

每筆紀錄可**編輯**（帶回表單，按鈕改「更新」，可取消）與**刪除**。

## 課表顯示

套用順序：**原課表 → 調課 → 代課**。

| 情況 | 格子 |
| --- | --- |
| 調出 | 灰色標籤「調出→週三 3」，格子清空或換成對調的班 |
| 調入 | 藍色標籤「調入←週一 2」＋班級 |
| 我代別人 | 橘色標籤「代課」＋班級＋「代 王老師」 |
| 別人代我 | 灰色標籤「由 王老師代」，原班級變淡，視為空堂 |

「現在／接下來」卡片套同一套：
- 當節是我代別人 →「代課 805（代 王老師）」
- 當節被別人代 →「由 王老師代（801）」，不顯示去上課按鈕

### 近期清單

表單下方列出**今天起**的調課與代課，依日期排序，每筆顯示種類、日期星期節次、班級、對方老師、備註、編輯／刪除。過去的紀錄收在「過去紀錄」（`<details>`），預設收合。

原本的「檢視週」選單保留，用來切換課表顯示的週次，不再參與表單輸入。

## 驗證

1. **舊調課相容**：用合成的舊格式調課資料（同週、跨週各一），升級前後課表格子內容相同
2. 新調課用日期存：同週與跨週都正確；跨週目標有課會跳確認
3. 我代別人：該格出現代課與班級；衝堂會跳確認
4. 別人代我：該格顯示「由某老師代」；空堂會跳確認
5. 週末／國定假日日期無法存
6. 編輯舊調課：表單正確帶回日期；更新後課表即時變化
7. 刪除後課表恢復
8. 後端合併（mock）：本機沒有 `substitutes` 時，雲端代課不被清掉；所有欄位保留
9. 座位卡正常、無 JS 錯誤

## 風險

- 自動帶班級依賴課表格子文字能被 `matchClassName` 辨識；辨識不到時改為手填
- 部署 `Code.gs` 前，代課資料只靠前端合併保護；若有舊後端版本，跨裝置同步可能遺失代課 → 實作完成後須提醒老師立即更新部署
